# 365step: направления и режим фокуса — спецификация реализации

Источник: ТЗ версии 1.0 из текущего чата, writing block 48371; пользователь запросил реализовать всё недостающее на локальном сайте.

## Обязательный результат

27 направлений, ровно пять модулей в каждом, ровно одно активное направление у ученика. Первый экран регистрации — полный каталог с поиском, одиночным выбором и просмотром модулей. Специальность — необязательное уточнение внутри направления. Профориентационный опрос советует, окончательный выбор делает ученик. Экзамены подключаются отдельно по подтверждённым целям. Нет профиля по умолчанию для старых аккаунтов.

После выбора все учебные поверхности показывают опубликованный контент направления и подходящие общие материалы: боковое/мобильное меню, док, главная, путь, библиотека, поиск, рекомендации, задания дня, повторение, уведомления, ИИ. Междисциплинарные материалы включаются в модуль выбранного направления, а не открывают чужой каталог. Прямые ссылки на чужое направление получают объяснение с возвратом к своему маршруту.

Смена: Профиль → Настройки обучения → Дополнительные параметры → Сменить профиль обучения. Выбор и предварительный просмотр, затем подтверждение; атомарная смена, версия настроек, уведомление других вкладок, сброс старых запросов. Прогресс предыдущего направления сохраняется и восстанавливается при возвращении. Тариф, аккаунт, XP, серия, проекты и экзаменационные результаты сохраняются. Черновики сохраняются до переключения. Перенос компетенций — только по явной карте соответствий.

## Учебное наполнение и источники

Целевая комплектация полной версии: на каждый из 135 модулей минимум пять содержательных уроков, 30 самостоятельных заданий, один кейс/мини-проект с рубрикой, итоговое оценивание, два проверенных ресурса. Итого минимум 675 уроков, 4050 заданий и 135 кейсов/проектов. Переводы и числовые вариации не увеличивают число самостоятельных задач. Уровни: Старт, Практика, Вызов. Есть входные требования, короткая диагностика с пропуском, результаты обучения, последовательность и повторение. Непроверенная генерация не называется проверенным заданием.

Существующие экзаменационные банки сохраняются; профильный курс не выдаётся за официальный пробник. Существующие Arduino/CAD/роботы/дроны/кодинг связываются с модулями, записи истории не переписываются.

## Остальные требования

Сохранить ЕНТ-2028 для 10-го класса в 2026/27 учебном году и приоритет явного выбора года. Собственные результаты экзаменов и проектов не исчезают при скрытии раздела. Текущие экзаменационные попытки старых пользователей можно завершить до выбора направления.

Редактор с уже существующими административными правами управляет каталогом, модулями, ресурсами, связями, зависимостями, публикацией, проверяющими и предварительным просмотром. Публичная регистрация не выдаёт административные права. Процесс: черновик → методическая проверка → проверка ответа/рубрики → проверка прав → публикация.

Финальная приёмка: все сценарии раздела 11 исходного ТЗ; одиночный выбор, прямой API, поиск и прямые ссылки, переключение туда/обратно, другие вкладки/устройства, старые аккаунты, отсутствие утечек ответов, клавиатура/экранный диктор, полная комплектация. Флаги промежуточного внедрения допустимы до финала; пустые модули не обозначаются готовыми курсами.
