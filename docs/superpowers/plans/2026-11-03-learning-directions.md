# Learning Directions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Реализовать всё отсутствующее из ТЗ 1.0 на локальном 365step: 27 направлений, 135 наполненных модулей и согласованный кабинет одного профиля без потери существующего прогресса.

**Architecture:** Статический типизированный реестр постоянных ID плюс редактируемые версии контента в SQLite/Turso. Отдельная строка learning_profiles хранит единственный активный профиль и версию; единая политика видимости используется серверными API и всеми клиентскими навигационными поверхностями. Экзаменационные банки и существующий прогресс сохраняются, новые учебные попытки, проекты и повторения имеют собственные постоянные ID.

**Tech Stack:** React 19, TypeScript, React Router, Express, @libsql/client, существующий Vite/esbuild, Node.js 24; без новых обязательных внешних API.

**Spec:** ../specs/2026-11-03-learning-directions.md; исходное ТЗ 1.0 (writing block 48371 текущего чата).

## Global Constraints

- «Один ученик → одно активное направление → один согласованный учебный интерфейс».
- «27 направлений и 135 модулей»; пять модулей на направление, названия зафиксированы в спецификации.
- «не менее пяти содержательных уроков», «не менее 30 самостоятельных заданий», «хотя бы один кейс или мини-проект», итоговое оценивание и два проверенных ресурса в каждом модуле.
- «Направление пользователя определяется из его профиля, а не произвольного параметра запроса».
- «Прогресс предыдущего направления сохраняется и восстанавливается при возвращении»; тариф, XP, серия, проекты и экзамены сохраняются.
- «Основная навигация, собственные уроки и внутренние задания работают без API сторонних образовательных платформ».
- Русский, казахский и английский интерфейсы; язык источника хранится отдельно; непроверенные переводы не выдаются за проверенные.
- 10-й класс 2026/27 → ЕНТ-2028; ручной выбор имеет приоритет.
- Источники NC/ND — внешние ссылки, если отдельное разрешение на импорт отсутствует. Старые банки не переписывать и не переоценивать массово.
- Локальный сайт: http://localhost:8787. Испытания только на отдельной копии БД. Внешнюю публикацию этим запросом не запускать.

## Review Focus

1. Две вкладки одновременно меняют профиль: одна операция проходит, устаревшая получает 409; попытки и проекты не теряются. Проверка Core/Task 2.
2. Старый сетевой ответ возвращается после переключения аккаунта/профиля: данные старого пользователя/направления не отображаются. Проверка Experience/Task 2.
3. Старая ссылка, запрос к API или уведомление ведут в чужой профиль: ученик видит объяснение, сервер не отдаёт чужой учебный каталог. Проверки Core/Task 3 и Experience/Task 3.
4. Внешняя ссылка стала платной/недоступной или не допускает перевода: внутренний урок работает, карточка источника имеет честный статус; публикация импорта блокируется без прав. Проверка Content/Task 1.
5. Повторная отправка ответа/проекта и смена профиля в середине попытки: XP начисляется один раз, черновик и история сохраняются; экзамен может быть завершён по владельцу попытки. Проверка Content/Task 2.
