# SAT English 4,200 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Expand the local English bank from 1,009 to approximately 4,200 distinct questions, comparable to Math.

**Architecture:** Retain all existing records and option mappings. Import licensed human-authored reading questions, preserve their original keys, and add explicitly labeled source-based practice with reproducible transformations. Separate full-test eligibility from reinforcement.

**Tech Stack:** Existing TypeScript/React/Express; offline Python import with standard library only.

**Spec:** User request: English should have approximately as many questions as the 4,000-question Math bank.

## Global Constraints
- No College Board, research-only, NC-only or unlicensed question bank copying.
- Preserve original questions/keys, existing progress, exam-first navigation and chosen direction.
- Four distinct visible choices; source, locator, license and origin retained.
- Report generated/adapted practice separately; no option permutations counted as additional questions.
- No runtime source APIs; leave localhost available.

## Review Focus
- Exclude unsupported source questions and broken context rather than trimming evidence away.
- Source-derived distractors are practice, not independently validated assessment questions.
- Grammar transformations must have a clear structural rule and preserve the original correct wording.
- Repeated passages and families must remain restricted in tests and drills.
- Source license, data checksum, original answer and adaptation must be independently auditable.
