# Большой дополнительный банк ЕНТ — 3 ноября 2026

Добавлено **6 700 языковых записей**, соответствующих **4 337 условиям по идентификаторам источников** без повторного подсчёта переводов. Вместе с прежними 1 901 записями в разделе доступно **8 601 записей**. Предыдущий набор и попытки сохранены.

Это дополнительная предметная практика из опубликованных учебных и исследовательских наборов. Она не называется официальным банком НЦТ и не подменяет полный пробник ЕНТ. В исходниках есть задания других экзаменов и короткие вопросы на фактические знания; часть сложнее типового школьного уровня. Полного соответствия каждому пункту спецификации ЕНТ и экспертной оценки сложности всех импортов пока нет.

## Что доступно

На странице `/ent/bank` работают поиск, фильтры по 16 предметам, языку, источнику, формату, последней ошибке и нерешённым заданиям. Можно открыть отдельный вопрос или подборку до десяти заданий. Условия, варианты, исходные отрывки, формулы и блоки кода сохранены. Источник и граница проверки доступны для каждого задания. Верный ответ, пояснение и подтверждающий фрагмент открываются после проверки.

Отдельная история `ent_source_attempts` сохраняет прогресс между запусками. Сначала выбираются нерешённые записи; после исчерпания доступны повторения. Переводы одного условия не попадают одновременно в одну подборку. Эта коллекция пока не включена в прежнюю очередь FSRS и адаптивный мастер-режим. Основной полный пробник по-прежнему состоит из 120 вопросов с максимумом 140 баллов из прежнего банка.

Хеши входных файлов находятся в `import-audit.json`; версии и доказательства лицензий — в `source-permissions.json`. ## Отбор и проверка содержания

Из KazQAD выбирается один исходный вопрос из нескольких подтверждающих отрывков. Требуется однозначная аннотация, точное совпадение ответа с исходным смещением и дополнительная лексическая связь вопроса с предложением. Неполные перечисления, несогласующиеся ответы, недостаточные доказательства, вопросы без нужного рисунка и выявленные ошибки исключены. Подтверждение показывается после ответа. Такая проверка **не равна независимой проверке исторического или научного факта**.

В MERA исключены профессиональные и медицинские домены, специальные инструменты информационной безопасности, чужое национальное право, недостающие изображения/таблицы, испорченные формулы и переменные, длинные сторонние литературные цитаты. Из права оставлено 10 отдельно просмотренных вопросов общей теории. Задания USE явно обозначены как дополнительная тренировка русского языка по открытому сборнику ЕГЭ. Ответы сохраняются из опубликованного ключа; вымышленных развёрнутых решений не добавлено. Большинство ключей MERA, INCLUDE и Belebele **ещё не пересчитано или решено независимо для каждого вопроса**.

В ходе выборочного просмотра удалены, например, вопрос с ошибочным утверждением о выделении АДГ почками, неправильное сопоставление полушария и Гондваны, смешение молока кобылы и кумыса, неполная химическая реакция без вопроса, неверная трактовка интеграции как сегрегации и повреждённые математические условия. В одном вопросе исправлен перевод NADH/НАДН, ошибочно названного НАДФ; исходное условие и правка сохранены в `source-corrections.json` и объяснении. В одном параллельном вопросе Belebele уточнён фокус на субтитрах во всех трёх языках, чтобы исключить второй подходящий вариант; исходный ключ не изменён. Идентификаторы и причины сохранены в `scripts/ent-content/source-exclusions.json`, обзор проверки — в `review-log.json`.

В OpenStax переиспользуются конкретные уже проверенные упражнения SAT, а не новые числовые перестановки. Простая разминка исключена. Эти 569 условий уже есть в SAT: это прирост доступного материала ЕНТ, а не 569 новых условий во всей платформе. Их ответы сверены с независимыми символьными эталонами прежнего этапа. Только эта часть дополнения имеет редакционные метки B/C; исходные неоценённые вопросы не названы автоматически сложными.

Belebele содержит обычно один-два вопроса на отрывок; из них не создаются искусственные пятизаданные контексты ЕНТ. RuBQ — тренировка фактов литературы с ответами-сущностями и русскими вариантами названия; вопросы о кино, памятниках, семейных мелочах и неоднозначных датах написания исключены.

## Воспроизведение импорта

Приложение читает готовый `server/content/ent/source-data.json`. Интернет во время тренировки не требуется. Для обновления офлайн-импорта установите `scripts/ent-content/requirements.txt`, подготовьте источники с версиями из `source-permissions.json` и запустите:

```sh
python3 scripts/ent-content/import-sources.py --sources /absolute/path/to/sources
npm run export:ent-sources
npm run check:ent-sources-api
npm run build
```

Каталоги источников: `kazqad/data/reading-comprehension`, `rubq/RuBQ_2.0`, `mera/download/data/{rummlu,use,mathlogicqa}`, `include/download/Kazakh` и `belebele/download`. MERA и INCLUDE скачиваются по обычным HTTPS resolve-ссылкам Hugging Face, закреплённым commit SHA; исходный Git-снимок нужен для сверки хешей. Belebele — официальный `https://dl.fbaipublicfiles.com/belebele/Belebele.zip`, файлы `rus_Cyrl.jsonl`, `kaz_Cyrl.jsonl`, `eng_Latn.jsonl`. OpenStax берётся из сохранённого в проекте `shared/satScaleSource.json` и его эталонов. Список и хеш каждого прочитанного файла записывает сам импортёр.

## Проверки и состояние

Результаты окончательного запуска сохранены в `validation-results.json`: 112 229 проверок структуры/формул/ключей дополнения; 2 082 проверки API большого банка; 3 769 проверок прежнего ЕНТ по всем 16 предметам и 24 комбинациям полных пробников; 114 общих проверок API; 4 583 регрессионных проверки; 47 проверок года экзамена. Проверка типов и обе сборки прошли. Структурные проверки не означают независимого решения каждого импортированного задания. Проверялись формулы, валидность ключей и вариантов, отсутствие ключа/доказательства в выдаче до ответа, сохранение исходных отрывков, языки и предметы, фильтры, проверка ответов, порядок повторений, восстановление истории после перезапуска и основной полный пробник на временных данных. Отдельно повторно проверено сохранение ЕНТ 2028 для 10 класса.

Результат доступен в локальном просмотре на `http://localhost:8787/ent/bank`. Публичная версия сайта этим этапом не обновлялась. Пользовательская рабочая база не изменялась; браузерная проверка использует отдельную QA-копию. Изменения других разделов, выполненные ранее, сохранены.
