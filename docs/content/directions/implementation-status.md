# Актуальное поведение: экзамены — основа платформы

Уточнение пользователя от 3 ноября 2026 заменяет прежний режим фокуса:

- Основные разделы восстановлены как прежде: ЕНТ → SAT → IELTS, затем прежние инструменты и служебные пункты.
- После ЕНТ → SAT → IELTS вместо универсальных блоков «Кодинг» и «Инженерия» показывается одно выбранное направление с его пятью модулями. Инструменты IT или инженерии включаются только для соответствующего выбора.
- Последний пункт навигации — «Направление»: каталог выбора/смены направления. В нём доступны все добавленные направления и сохранённые проекты.
- Направление необязательно при регистрации и не закрывает экзамены, библиотеку, кодинг или инженерные инструменты.
- Главная, учебный путь, регистрация, библиотека и поступление возвращены к прежнему экзаменационному интерфейсу.
- Данные направлений и ранее выполненная работа сохраняются; ограничения области применяются только внутри дополнительных профильных модулей.

Ниже — исторический отчёт предыдущей версии. Его требования об обязательном выборе и скрытии экзаменов больше не действуют.

# 365step: направления обучения

Дата: 3 ноября 2026. Локальный адрес: http://localhost:8787/learn.

## Что реализовано

- 27 направлений бакалавриата/специалитета, 135 модулей с постоянными ID, описаниями и специальностями. Каталог включает технологии, бизнес, общественные и гуманитарные науки, образование, здоровье, естественные науки, искусство, сервис и спорт.
- Каталог на первом экране регистрации: поиск по профессиям и синонимам, одиночный выбор, предварительный просмотр пяти модулей, необязательная специальность. Для неопределившихся — подсказка по интересам, без автоматического назначения профиля.
- Старые аккаунты выбирают направление сами; IT по умолчанию не назначается. Класс и экзамены сохраняются отдельно от профиля. SAT, IELTS, ЕНТ и NUET подключаются явно; можно учиться без экзаменов.
- Главная, учебный маршрут, боковое и мобильное меню, быстрые действия, библиотека, поиск, повторение и подбор конкурсов используют активное направление. Проверка фокуса действует и на сервере. Начатые собственные экзаменационные попытки можно завершить.
- Смена через «Профиль → Дополнительные параметры → Сменить профиль обучения»: предварительный выбор и подтверждение. Версия профиля защищает от конфликтов двух вкладок. Старые ответы, XP, тариф, проекты и результаты экзаменов сохраняются. Устаревшие сетевые ответы не подменяют новый кабинет.
- Авторские практикумы, числовые ответы с автоматической проверкой, открытые упражнения с критериями, черновики проектов, портфолио, необязательная стартовая диагностика. Черновик восстанавливается после перезагрузки; конфликтующая локальная версия показывается для ручного восстановления.
- 54 размещения ссылок на 35 различных бесплатных образовательных страниц/каталогов. Внешние материалы открываются у издателя; тексты не импортировались. Бесплатность доступа не используется как разрешение на копирование. Собственная практика не зависит от API образовательных сайтов.
- Редактор для существующих администраторов: версии черновиков, предметная, языковая и правовая проверки другим редактором, публикация проверенной версии. Новых администраторов в пользовательской базе не создавали. Для проектов есть очередь проверки, пять критериев 0–4 и комментарий преподавателя.
- Контекст Telegram-помощника учитывает активный профиль, его прогресс и выбранные экзамены. Отправка сообщений в Telegram в ходе проверки не выполнялась; работа внешней модели не проверялась в демо-режиме.

## Учебный объём и его границы

Подготовлено 135 авторских учебных кейсов. Каждый разделён на пять этапов: модель, метод и расчёт, доказательства, прототип, защита. Это 675 страниц-этапов, 135 расчётных упражнений, 3915 открытых учебных действий и 135 проектов.

**4050 учебных действий не означают 4050 независимых экзаменационных задач.** Открытые действия используют общую методическую структуру на разных предметных кейсах. Это вводные практикумы для знакомства с направлениями; они не заменяют полные университетские курсы. Отправка открытого ответа не подтверждает его правильность. XP за такую работу обозначает учебную активность.

Независимая предметная редактура стартовых кейсов ещё не выполнена. Этот статус виден в модуле. Опубликованные редактором версии требуют отдельных проверок; сам автор не может отметить независимую проверку своей версии.

Интерфейс новой версии русский. Для названий направлений есть русские, казахские и английские метаданные; полная локализация интерфейса и курсов на казахский и английский из расширенного плана ещё не выполнена. Редактор работает с существующими 135 модулями; произвольное создание новых направлений через интерфейс редактора пока не реализовано.

## Проверки

- TypeScript, клиентская сборка Vite и серверная сборка esbuild — пройдены.
- Каталог: 27 направлений, по пять модулей, уникальные ID, поиск синонимов, матрица доступа ко всем 135 модулям — пройдены.
- Новый API: транзакционная регистрация, одновременная смена профиля с одним победителем, сохранение истории, закрытые ключи ответов, изоляция аккаунтов, идемпотентные попытки и начисление XP, конфликты черновиков — пройдены.
- Редактор: права, конфликт версий, запрет самопроверки, независимые проверки, публикация, оценка проекта, диагностика с пропуском — пройдены.
- Прежний контент: 4583 регрессионные проверки — пройдены.
- Общий экзаменационный API: 114 проверок — пройдены.
- ЕНТ: 3769 проверок, 16 предметов, два языка интерфейса и 24 комбинации полного пробника — пройдены.
- ЕНТ из открытых источников: 2082 проверки по 27 комбинациям источника/предмета/языка/формата — пройдены.
- Год ЕНТ: 47 проверок; 10 класс в 2026/27 → 2028, ручной год имеет приоритет — пройдены.
- В браузере: переход старого аккаунта к выбору, отдельный тестовый кабинет бизнеса, восстановление ответа/черновика, поиск «стоматолог», подтверждение смены на медицину и перестройка меню — пройдены.

Проверки API выполнялись на временных базах с вымышленными пользователями. Предпросмотр использует прежнюю отдельную QA-базу; исходная пользовательская база проекта не заменялась. GitHub/Vercel этой работой не публиковались.
