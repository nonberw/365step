## Поведение сайта

В банке появились «Большой набор», «Источники и Reading» и «Тренировочные
варианты». Назначение и сложность можно фильтровать совместно. Счётчики
отдельно показывают исходные упражнения, новые RW, варианты и семейства.
Семейства чередуются, чтобы первые страницы не состояли из одинакового шаблона.

Варианты отмечены «Вариант для закрепления» в списке и в карточке. Они доступны
в банке, тематических занятиях и Hard-тренировках, но не в полном пробнике.
В одной тренировке допускается максимум два варианта одного семейства.
Полный пробник сохраняет ограничение повторов семейств и условий между модулями.
Старые ID, ответы и история пользователя сохранены.

Для каждого задания доступны происхождение, лицензия, описание изменений и
скачиваемая версия. Сайт использует готовые данные: во время решения нет
скачивания сторонних заданий, Python или внешних API.

## Воспроизведение

Python-зависимости зафиксированы в `scripts/sat-scale-requirements.txt`.
Получить архив OpenStax нужно из `codeload.github.com` по точной версии выше;
импортёр отклонит архив с другой версией или другим заголовком лицензии.

```sh
python3 scripts/build-sat-scale.py --archive /path/to/openstax-2026-08.zip
python3 scripts/build-sat-practice.py
python3 scripts/verify-sat-scale.py
node --import tsx scripts/export-sat-scale.ts
node --import tsx scripts/check-content.ts
node --import tsx scripts/content-regressions.ts
node --import tsx scripts/content-api-check.ts
```

Генерация детерминирована (seed 36520261103). Из OpenStax принимаются только
самодостаточные выражения с поддерживаемой математикой и полным точным ключом.
Задания с отсутствующими схемами, таблицами, неопределёнными вызовами функций,
темами вне выбранной программы и неподдерживаемой записью отбрасываются.
Матрицы, логарифмические и тригонометрические тождества, calculus не импортируются.
Десятичные коэффициенты переводятся в точные рациональные числа.

Независимые проверочные входы находятся в `scripts/sat-scale-reference`,
отдельно от публичного объекта вопроса. Они не выдаются API до ответа.
Файл скачивания явно содержит ключи для повторного использования контента.

  отсутствие ключей в объекте вопроса до ответа, полный пробник на 98 заданий,
