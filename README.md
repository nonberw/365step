# 365step

B2C EdTech: личный ИИ-наставник для **Digital SAT, IELTS, ЕНТ и программирования**. Ученик сам регистрируется, получает 7 дней Pro, строит путь до даты экзамена и занимается с ИИ. Это новая версия 365step: основа — «Проект 125» (BSTS AI Lab), из которого убраны школьные роли и добавлены тарифы; из прежней версии 365step перенесены банк заданий, цели поступления (страна, направление) и каталог конкурсов.

## Запуск

Нужен Node.js 24+ (встроенный `node:sqlite`).

```bash
npm install
npm run dev
```

Сайт: http://localhost:5317, API: http://localhost:8317. Ключ Claude — `ANTHROPIC_API_KEY` в `.env` (образец — `.env.example`). Без ключа ИИ отвечает шаблонами. Проверка ключа (один платный запрос): `npm run ai:check`.

Сбросить данные: остановить сервер и удалить папку `data/`.

## Что изменилось по сравнению с «Проектом 125»

| Было (B2B, для школы) | Стало (B2C) |
|---|---|
| Роли ученик / учитель, коды классов, кампусы | Одна роль: сам зарегистрировался и учишься |
| Контрольные по коду, журнал, живой урок, отчёт завуча | Убраны. Остались личный план, дуэли, рейтинг, отчёты родителям |
| Всё бесплатно по школьной лицензии | Тарифы **Старт** (8 ИИ-ответов в день) и **Pro** (без лимита), 7 дней Pro при регистрации |
| Цель: балл SAT/IELTS | Плюс страна поступления и направление, страница **Поступление** с 48 конкурсами и программами |

### Тарифы и лимиты

- `server/quota.ts` считает ИИ-ответы по дням. Каждый запрос к модели в `server/ai.ts` сначала проходит `consumeAi()`: у Старта после лимита приходит ошибка 402 с призывом перейти на Pro, у Pro лимита нет.
- `GET /api/billing` — тариф, остаток ИИ-ответов; `POST /api/billing/trial` — пробный период (один раз); `POST /api/billing/checkout` — оплата.
- **Платёжный провайдер не подключён.** Пока `BILLING_MODE` пуст, оформление платного тарифа закрыто; `BILLING_MODE=demo` продлевает Pro без оплаты — только для показа. Для боевой оплаты нужен провайдер (Kaspi, CloudPayments, Stripe) и вебхук, который выставляет `plan` и `plan_until`.
- Цены в `src/pages/Pricing.tsx` и `server/routes/billing.ts` (4 990 ₸/мес, 39 900 ₸/год) — рабочие заглушки, их нужно утвердить.

### Дизайн

Лендинг и тема собраны по мотивам folk.com и grader.cloud (стиль, не их бренды и не их материалы):

- от folk: переписка с ИИ в телефоне, эмодзи-наклейки с белым контуром, пастельно-голубые карточки 2×2 с «пузырями» сообщений, заголовки с засечками (Lora), строчные тексты, глянцевые синие кнопки, крупный логотип в финальном блоке;
- от grader: небо в первом экране (CSS-градиент, облака и горы без картинок), плавающее стеклянное меню, стеклянные панели с баллами и планом ИИ, строка цифр, чередующиеся блоки Speaking / Writing / SAT с макетами продукта.

Шрифты с кириллицей: Lora (заголовки) и Onest (текст). Код лендинга: `src/pages/Landing.tsx`, `src/pages/landing/PhoneChat.tsx`, `src/pages/landing/Showcase.tsx`. В кабинете остались док и уведомления из 21st.dev; компоненты прошлого лендинга (`prisma-hero`, `bento`, `hero-1`, `hero-10`, `wireframe-dotted-globe`) лежат в `src/components/ui/`, но сейчас не используются.

### Регистрация как онбординг (как у grader)

`/register` начинается с экрана приветствия: небо, растение-маскот, «Начать» и «У меня уже есть аккаунт». Дальше вопросы по одному на белой карточке с полосой прогресса, растение коротко реагирует на каждый ответ: класс, экзамены (SAT, IELTS, ЕНТ, код), целевой балл и дата по каждому (официальная дата SAT, месяц IELTS, сессия ЕНТ), уровень, что даётся труднее, минуты в день, выбор растения. Потом одно пробное задание, четыре карточки «чему научит план», пауза «анализирую цель» и экран «Твой персональный план готов!» с целью, сроком и планом на 4 этапа. Аккаунт создаётся последним шагом; ответы сохраняются в цели ученика, а путь открывается на курсе первого выбранного экзамена. Пока анкета не закончена, ответы лежат в sessionStorage. Вход (`/login`) в том же стиле.

### Поступление: заявки, эссе, портфолио

`/admissions` — рабочее место для подачи (`server/routes/admissions.ts`, страницы в `src/pages/admissions/`):

- **Мои заявки** — вузы с системой подачи (ED/EA/RD, UCAS, Европа, Азия, Казахстан), дедлайном и обратным отсчётом, статусами (в списке → готовлю → подал → результат) и чек-листом под систему (Common App: эссе, supplements, рекомендации, activities, CSS Profile; UCAS: personal statement и reference). Отправленная заявка даёт +30 XP растению.
- **Эссе с ИИ** — черновики Common App (7 вопросов), «Why us», UCAS (3 вопроса) и мотивационного письма со счётчиком слов или знаков. ИИ работает как коуч: брейншторм (вопросы, углы, план), отзыв по рубрике (крючок, конкретика, рефлексия, голос, структура, ответ на вопрос) с цитатами из текста. Эссе он не пишет и не переписывает — это правило стоит и в интерфейсе, и в системном промпте.
- **Портфолио** — мост от лаборатории к поступлению: пройденные миссии с дроном, детали в CAD, проекты на Arduino, роботы URDF, решённые задачи и уровни пути сами становятся фактами, которые одной кнопкой превращаются в пункт Activities для Common App (роль до 50 знаков, описание до 150, ИИ берёт только факты ученика). Справа — 10 слотов Activities и конкурсы под навыки ученика.
- **Конкурсы** — прежний каталог из 48 программ.

Исследование о том, как платформы помогают с поступлением и где граница честной помощи ИИ с эссе: `docs/research/admissions-help.md`.

### Инженерная лаборатория: обновления

- Синхронизировано с [baipeissov/athenaide](https://github.com/baipeissov/athenaide) на 29.10.2026: модуль «своё устройство из блоков» (`src/lib/athena/assembly/`), новый `deviceGraph.ts` и словарь `locales/ru.ts`. Остальные файлы симулятора совпадали; автопроверка Arduino (`npx tsx scripts/arduino-check.ts`) проходит. Отдельное приложение «захват под деталь» (`gripper/` в athenaide) пока не перенесено.
- **Робот → URDF** (`/engineering/robot`) на основе [nwo-text-cad](https://github.com/RedCiprianPater/nwo-text-cad) (MIT, копия в `vendor/nwo-text-cad`): манипулятор, колёсный или четвероногий робот → файл URDF со звеньями, суставами, началами координат и инерцией, плюс стартовые настройки 3D-печати. Генератор CAD в nwo-text-cad 0.1.0 — заготовка (экспорт пишет строку-комментарий), поэтому детали по-прежнему строит наша CAD-лаборатория. Скачанный робот засчитывается в портфолио.

### Экосистема разделов

Все разделы связаны одним растением, одним XP и серией, общим планом с датами экзаменов и общим повтором ошибок:

- **Полоса «Мой план»** сверху каждой страницы кабинета (`src/components/Ecosystem.tsx`): растение и его стадия, серия, XP, обратный отсчёт до SAT, IELTS и ЕНТ из целей ученика и ссылки «связано» на разделы, которые питают текущий (например, SAT → путь SAT Math и R&W, повтор ошибок, поступление).
- **Общий баннер разделов** (`GreetingBanner`): небо с облаками, бейдж Hero Pill из 21st, заголовок с засечками и растение ученика справа. Такой же стиль у собственных hero ЕНТ, дуэлей, повтора, родителей и инженерии.
- **Схема экосистемы** (`EcosystemMap`): растение в центре и шесть разделов вокруг. Она есть на лендинге (блок «всё связано») и в итоговом плане регистрации, где подсвечены выбранные экзамены.

Даты экзаменов (`shared/examDates.ts`): SAT — официальные даты College Board 2026–27 с крайними сроками регистрации (они общие для всех стран) и предварительные даты 2027–28; IELTS — выбор месяца (компьютерный IELTS проходит почти каждую неделю); ЕНТ — сессии 2027 года по графику 2026, пока НЦТ не опубликовал новый.

### Путь обучения (как в Duolingo)

`/learn` — главная после входа. Пять курсов:

- **SAT Math** и **SAT Reading & Writing**: юниты — домены College Board, уровни — навыки, затем повторение юнита и сундук (+20 XP);
- **IELTS Reading**: юниты по типам заданий, уровень — один текст с вопросами;
- **ЕНТ**: юниты — три обязательных предмета и профильная пара ученика (выбирается в разделе «Подготовка к ЕНТ»), уровни — темы предмета. Задания берутся из банка ЕНТ; если по теме их меньше восьми, Claude дописывает новые при старте урока (до минуты ожидания, расходует ИИ-лимит). Грамотность чтения идёт текстами по пять вопросов;
- **Программирование**: разминка «Найди баг» обычным уроком, дальше юниты по темам алгоритмов (массивы, два указателя, …) и уровни-задачи. Задача решается в редакторе кода и засчитывается, когда пройдены все тесты. Уровни идут по извилистой дорожке и открываются по порядку, у каждого до трёх «корон»: с каждой короной задания сложнее. Растение, выбранное учеником, стоит рядом с текущим уровнем.

Урок (`/learn/:course/:node`) идёт на весь экран: полоса прогресса, сердечки (5 на урок, в Pro без ограничений), одно задание за раз, кнопка «Проверить», зелёная или красная плашка с разбором. Ошибки возвращаются в конец урока. Растение радуется верному ответу и грустит при ошибке. В конце: XP, точность и время. Клавиатура: 1–9 выбирают вариант, Enter проверяет и листает дальше.

Сервер (`server/routes/path.ts`) строит структуру курса из банков заданий, хранит короны в `path_progress`, а каждый урок — в `path_lessons`. XP за урок (10 + верные с первой попытки + 5 за урок без ошибок) считается только по ответам, которые проверил сам сервер. Справа на пути — цель дня по XP и три задания дня.

### Растение-спутник

Ученик выбирает кактус, сакуру, цветок или подсолнух (при регистрации или в профиле). Растение растёт на пяти стадиях по общему XP (0 / 40 / 150 / 400 / 1000), нарисовано в SVG (`src/components/Plant.tsx`), живёт в боковой панели и на главной. При переходе на новую стадию приходит уведомление. Пороги и названия — в `shared/plants.ts`.

## Банк заданий из 365step

`scripts/import-365step.ts` переводит банк `365step` в формат этого проекта и пишет `shared/bank365.json` (результат лежит в репозитории). Подключено:

- **SAT:** 1350 вопросов (R&W 495, Math 855) стали частью `SAT_BANK`: они видны в банке, пробных тестах, тренировках и повторе ошибок. Названия навыков совпадают с прежними, поэтому фильтры работают сразу. Таблицы и второй текст (cross-text) вставлены в текст вопроса.
- **IELTS Reading:** 63 текста, 315 вопросов в семи типах (True/False/Not Given, Yes/No/Not Given, matching headings и information, multiple choice, completion, short answer). На странице Reading теперь фильтр по типу и список текстов.
- **Writing Task 2:** 20 тем, **Speaking:** 20 карточек Part 1 и 20 Part 2 с вопросами Part 3.

Пересобрать: `npx tsx scripts/import-365step.ts "<путь к 365step>/src/content/bank"`. Не перенесены: поле `check` (формула проверки математики), Writing Task 1 (нужны данные графиков), Listening. У grid-in принимается первый из допустимых ответов (и равные ему дроби/десятичные); у 41 вопроса есть и другие допустимые записи, они теряются.
