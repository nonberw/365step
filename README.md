# BSTS AI Lab

Учебная платформа для школы: **Digital SAT**, **IELTS** и **программирование** (задачи как на LeetCode и уроки вайб-кодинга) в одном аккаунте, с кабинетом учителя и закрытым режимом урока.

Разбор 1609SAT, Grader AI и GoPrep, из которого взяты механики: `../research/разбор-конкурентов-и-выводы.md`.

## Запуск

Нужен Node.js 24+ (используется встроенный `node:sqlite`).

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. Сервер API работает на порту 8787, Vite проксирует к нему `/api`.

Claude: впишите `ANTHROPIC_API_KEY` в `.env` (образец — `.env.example`). Без ключа всё работает в демо-режиме с шаблонными ответами ИИ. Быстрая проверка ключа (делает один платный запрос): `npm run ai:check`.

## Деплой на Vercel

Сайт: https://proekt-125.vercel.app. Фронтенд собирается Vite, API работает как одна serverless-функция (`api/index.mjs` → `server-dist/app.mjs`, собирается `npm run build:server`). Ключ Claude задаётся в настройках проекта Vercel (`ANTHROPIC_API_KEY`), а не в репозитории. Обновить сайт: `npx vercel deploy --prod`.

Данные хранятся постоянно: база — Turso (libSQL, тот же диалект SQLite, подключена через Vercel Marketplace, переменные `TURSO_DATABASE_URL` и `TURSO_AUTH_TOKEN`), файлы учителей — закрытое хранилище Vercel Blob (`BLOB_READ_WRITE_TOKEN`), отдаются только через API с входом. Локально без этих переменных используются файл `data/bsts.sqlite` и папка `data/uploads`. Живой статус урока («кто в сети») тоже хранится в базе, потому что запросы на Vercel обслуживают разные экземпляры функции. Ограничение Vercel: загрузка одного файла — до 4,5 МБ.

### Отчёты родителям по пятницам

Vercel Cron вызывает `/api/cron/weekly` по пятницам в 18:00 по Алматы (`vercel.json`). Нужны переменные:

| Переменная | Зачем |
|---|---|
| `CRON_SECRET` | защищает `/api/cron/*` (Vercel передаёт его сам) |
| `RESEND_API_KEY`, `REPORT_FROM` | письма через Resend, адрес отправителя на подтверждённом домене |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME` | бот от @BotFather; после деплоя один раз `POST /api/cron/telegram-setup` с `Authorization: Bearer $CRON_SECRET` |
| `PUBLIC_URL` | адрес сайта для ссылок в письмах (по умолчанию берётся из запроса) |

Без этих ключей ссылка для родителей работает, но сама ничего не отправляет.

## Что есть

**Вход и регистрация**
- Ученик: 4 шага с вопросами (аккаунт → кампус и класс → цели SAT/IELTS, текущий балл, дата, минут в день, что сложнее всего, куда поступать → интересы и согласие на обработку данных). По ответам строится план на сегодня.
- Учитель: обращение (Мистер / Мисс / Миссис), предметы, кампус и код сотрудника. Платформа приветствует «Добрый день, Мисс Демо».
- Пароли — scrypt, сессии — токены на 30 дней. «Запомнить меня» выключается на общих школьных планшетах.

**Ученик**
- Главная: приветствие на картине (как в Tnkr), прогноз SAT и IELTS, XP, серия дней, план на сегодня, «Поработай над этим», тепловая карта года, задания учителя, рейтинг класса.
- **SAT** (механики 1609SAT): банк вопросов с фильтрами по 8 доменам, сложности и статусу; повтор ошибок и сохранённые; вопрос в стиле Bluebook (маркер текста, вычёркивание вариантов, пометка «на проверку», таймер); ИИ-объяснение ошибки, ИИ-подсказка без ответа и «Remix» — новый похожий вопрос от Claude; встроенный Desmos и справочник формул как в Bluebook (окно двигается и меняет размер); раздел «Учить Math и R&W» — 20 навыков отдельно по математике и английской части (идея, шаги, ловушки, пример, практика) и кнопка «Ещё 5 новых вопросов от ИИ», которые сохраняются в банк, так что он растёт; адаптивный пробный тест из 4 модулей — короткий (46 вопросов) или полной длины (98 вопросов, 2 ч 14 мин) — с режимом экзамена и разбором; ссылки на официальные бесплатные материалы College Board (Bluebook, Question Bank, Khan Academy); Blitz (3 жизни, множитель серии); словарь (карточки, текст, квиз); ИИ-план; аналитика; калькулятор баллов.
- **IELTS** (механики Grader и GoPrep): Speaking Part 1–3 с распознаванием речи в браузере и оценкой по 4 критериям; Writing Task 1 (график) и Task 2 с ошибками, подсвеченными прямо в тексте; Reading (T/F/NG, выбор, пропуски); Listening, который озвучивает браузер; игра «Не молчи» по микрофону; калькулятор общего балла.
- **Кодинг**: 20 задач как на LeetCode (условие, примеры, скрытые тесты, JavaScript и Python в браузере через Pyodide, история отправок, подсказки и ИИ-подсказка по коду ученика без готового решения); уроки вайб-кодинга; Bug Blitz.
- **Контрольная по коду**: когда учитель запускает контрольную, у всего класса через несколько секунд появляется красный баннер. Ученик вводит 6-значный код и пишет работу в режиме экзамена: таймер, навигация по вопросам, «проверить позже», автосохранение, отправка по времени. После отправки видна оценка, правильные ответы — когда учитель завершит контрольную для всех.
- **Библиотека**: встроенные авторские учебники (физика 7 «Энергия», квадратные уравнения, Python, грамматика SAT) и учебники, загруженные учителями (PDF читается прямо на платформе через pdf.js). К каждой странице — ИИ-панель: «Объяснить», «Конспект», «Тест», «Карточки», «Спросить», заметки. Функция в духе Every Joule на всех книгах: интерактивный опыт «предскажи → проверь → подними клапан → штамп "Понято"»; в главах встроенных книг есть готовые опыты, для любой страницы Claude собирает новый (выполняется в изолированном iframe без доступа к сети). Фильтры по предмету, классу 1–11 и языку, шпаргалки формул, форма «Не нашёл учебник?».
- **Доп. уроки и консультации**: расписание с недельным календарём (дни с занятиями отмечены точкой), фильтры по типу и предмету, запись в один клик с вопросом для учителя. Подтверждённая запись превращается в «билет» с отрывным корешком и штампом «Записан», его можно добавить в календарь (.ics). Места считаются атомарно: последнее место не достанется двоим. Ближайшая запись видна на главной.
- **Подготовка к ЕНТ**: выбор профильной пары (12 пар) и языка теста (русский или казахский), цель в баллах. Полный пробный ЕНТ в формате 2026–2027: 5 блоков, 120 заданий, 140 баллов, 240 минут; в профильном предмете 25 заданий с одним ответом, 5 контекстных, 5 с несколькими ответами и 5 на соответствие (2 балла, одна ошибка — 1 балл). Мини-пробник по одному предмету, тренировка по темам из спецификаций. Экран как в компьютерном ЕНТ: вкладки предметов, сетка заданий, таймер, калькулятор и таблица Менделеева. Результат с порогами по блокам и общими порогами 2026 года, карта анализа и разбор каждой ошибки от ИИ — то, чего нет у официального пробника. Задания оригинальные: ИИ пишет их по открытому формату, они сохраняются в банк школы, и он растёт. Ссылки на бесплатные материалы НЦТ (спецификации, образцы, пробник).
- **План до ЕНТ**: Claude строит адаптивный план от сегодняшнего дня до ближайшей сессии ЕНТ — 4 подробные недели (темы, тип практики, сколько заданий) и вехи по месяцам с целевым баллом. После каждого пробника и смены профиля план пересчитывается по новым слабым темам. Прогресс недели виден в разделе ЕНТ.
- **Повтор ошибок**: каждая ошибка в ЕНТ и SAT попадает в очередь интервального повторения и возвращается через 1, 3 и 7 дней; после трёх верных ответов подряд тема считается закреплённой. Счётчики на сегодня и прогноз на неделю.
- **Дуэли и лига класса**: вызов одноклассника на 10 заданий ЕНТ по предмету; оба решают одни и те же вопросы, побеждает больше верных ответов, при равенстве — время. Недельная лига класса по XP за ЕНТ, пробники и дуэли, обнуляется в понедельник.
- **Для родителей**: ученик создаёт личную ссылку для мамы или папы (до 4, отключается в любой момент). По ссылке без входа видна неделя: баллы ЕНТ, SAT, IELTS, задания учителя, контрольные, консультации, активность по дням и короткий отчёт от ИИ. По пятницам отчёт уходит на почту или в Telegram.
- Рейтинг: класс или вся школа, обнуляется каждый месяц.

**Учитель**
- Классы с кодом для учеников, таблица учеников (оценка SAT, точность, IELTS, решённые задачи, выполненные задания, активность).
- Задания классу: пробный тест SAT, N вопросов SAT, Writing, Speaking, задача по коду, урок, юнит словаря. Статус выполнения считается автоматически.
- Живой урок: выбор урока, закрытый режим, выключатель ИИ, кто в сети и кто вышел, журнал запросов к ИИ, приложение и код ученика, оценка 2–5.
- Карточка ученика: домены SAT, тесты, IELTS, уроки, слабые места.
- **Контрольные с ИИ**: учитель загружает материалы (PDF, DOCX, TXT, фото конспекта) или вставляет тему, выбирает класс, число вопросов, типы (выбор ответа, верно/неверно, короткий, развёрнутый), сложность и язык — Claude составляет черновик. Вопросы можно править, затем «Запустить для класса»: создаётся код, который можно вывести на проектор во весь экран. Живой монитор показывает, кто пишет, на каком вопросе, сколько ответил и кто выходил из экзамена; можно добавить 5 минут или завершить для всех. Результаты: тепловая таблица по вопросам, решаемость, работа каждого ученика, ручная правка баллов за развёрнутые ответы (ИИ проверяет их предварительно), CSV для журнала, «Провести ещё раз».
- Библиотека: загрузка учебников для всей школы и запросы учеников на новые учебники.
- **ЕНТ класса**: средний лучший балл класса, сколько учеников проходят пороги 50/65/70/75, средний процент по каждому блоку экзамена, самые слабые темы класса, распределение профильных пар и таблица учеников (лучший балл, цель, динамика пробников, баллы по блокам последнего пробника). Кнопка «Задать пробник»: полный ЕНТ или мини-пробник по предмету со сроком — выполнение отмечается само. Пока данных нет, страница показывает, как начать, и превью будущей аналитики.
- **Журнал оценок**: все оценки класса в одной таблице — контрольные с ИИ, оценки за уроки и письменные работы по фото. Проценты переводятся в пятибалльную оценку по порогам учителя. Выгрузка CSV для Excel и «длинная» таблица для переноса в Kundelik (ученик, работа, дата, оценка); прямого API у Kundelik нет.
- **Проверка по фото**: учитель фотографирует тетрадь (до 6 фото, сжимаются в браузере), пишет условие и критерии — Claude читает почерк, оценивает по критериям, показывает ошибки с цитатами. Учитель подтверждает или правит балл, и оценка попадает в журнал.
- **Доп. уроки и консультации**: учитель открывает время (личная консультация или групповой доп. урок, кабинет или ссылка на онлайн-встречу, для всей школы или одного класса, разово или каждую неделю), видит, кто записался и что хочет разобрать, может отменить занятие или всю серию — ученики увидят отмену.

**Инженерная лаборатория** (`/engineering`)
- **Дроны**: сборка квадрокоптера из каталога (5 рам, 5 моторов, 5 пропеллеров, 5 аккумуляторов, регуляторы, нагрузка). Расчёт по формулам: тяга T = Ct·ρ·n²·D⁴, мощность P = Cp·ρ·n³·D⁵, масса, тяговооружённость, ток висения и максимум, время полёта, прочность луча как консоли (σ = M·c/I, формулы из Athena IDE) и инженерные предупреждения (пропеллер не влезает, сгорит регулятор, сломается луч). 3D-модель собирается из выбранных деталей. Симулятор (`shared/droneSim.ts`): динамика твёрдого тела 6DOF на 1 кГц, инерция моторов, ветер и порывы, каскадный PID как в Betaflight/PX4 (положение → скорость → угол → угловая скорость → микшер). 7 миссий: первый взлёт, кольца, PID-лаборатория (график переходного процесса), доставка с грузом, автопилот на JavaScript (код ученика работает в Web Worker со сторожевым таймером), шторм, песочница. Проверки: `npx tsx scripts/drone-check.ts`, `scripts/drone-sim-check.ts`, `scripts/pid-check.ts`.
- **CAD и 3D**: 10 уроков параметрического моделирования кодом на ядре OpenCascade (replicad, как в Athena IDE): эскиз и выдавливание, отверстия, скругления, полые тела, массивы, крепление мотора, пересечение, тела вращения, луч рамы дрона, свой проект. Каждая деталь проверяется по габаритам, объёму и числу граней; экспорт STL для 3D-печати и STEP. Ожидаемые значения доказаны эталонными решениями: `npx tsx scripts/cad-check.ts`. Ядро (~23 МБ, 7 МБ в gzip) грузится только в CAD-лаборатории.

- **Arduino и электроника** (`/engineering/arduino`): симулятор макетной платы из Athena IDE, перенесён в `src/lib/athena` и `src/components/athena` почти без изменений (язык зафиксирован на русском, вместо большого хранилища проектов Athena — небольшое `store.ts`). Интерпретатор C++ для Arduino Uno с временем как на 16 МГц, расчёт напряжений и токов, мультиметр, логический анализатор, монитор порта, сгорающие без резистора светодиоды, редактор схемы на макетной плате. 11 уроков (`src/lib/athena/lessons.ts`): мигание, монитор порта, кнопка, светофор, ШИМ-диммер, сервопривод, ультразвуковой датчик, парктроник, ночник, термометр на дисплее, робот, объезжающий препятствия. Каждый урок проверяется автотестом симулятора; `npx tsx scripts/arduino-check.ts` доказывает, что эталонный скетч проходит, а заготовка — нет.

- **ИИ-конструктор** (`/engineering/cad-studio`): деталь по описанию словами или по фото эскиза с размерами. Claude пишет параметрический код replicad, браузер строит его на OpenCascade, ошибку ядра ИИ видит и исправляет сам (до двух попыток). История версий, правка параметров вручную, экспорт STL/STEP.
- **Arduino**: вкладка «Сборка по шагам» (пошаговая инструкция проводки из Athena IDE) и ИИ-наставник, который видит скетч, ошибку компиляции и результат автопроверки и подсказывает, не решая урок целиком.
- **Дроны**: журнал полёта как blackbox (высота, скорость, ток, батарея, экспорт CSV), редактор маршрута — точки на карте превращаются в код автопилота, сравнение до трёх сборок.

**Вайб-кодинг Pro**: история версий приложения с возвратом к любой, консоль с console.log и ошибками приложения и кнопкой «Попросить ИИ исправить», подсветка кода, просмотр как на телефоне и планшете, публичная ссылка на приложение (`/share/:token`, снимок в песочнице).

**ЕНТ · мастер-режим** (`/ent/master`): адаптивный тест на теории тестирования (IRT). Ответ вписывается, а не выбирается. Задания: трудные задачи уровня C/D, которые пишет ИИ по слабым темам ученика, и вопросы банка с коротким ответом. Сложность каждого задания стартует от уровня спецификации и калибруется по ответам всей школы; уровень θ ученика — EAP по всем его ответам ЕНТ (с учётом угадывания в обычной практике), следующее задание — максимум информации Фишера среди наименее отработанных тем (jsCAT). Прогноз баллов ЕНТ с 90 % интервалом и карта освоения тем (BKT). Проверка движка на смоделированных учениках: `npx tsx scripts/irt-check.ts`. Повтор ошибок ЕНТ и SAT переведён на FSRS (ts-fsrs).

**ИИ-конструктор, ускорение и база знаний**: первый ответ на низком effort (7–18 с вместо ~35), повторный запрос — из кэша; модель сообщает ожидаемые габариты, браузер сверяет их с построенной деталью и отправляет расхождение на исправление. Проверенные детали копятся в библиотеке школы и подставляются в запрос как примеры (RAG); учитель скачивает их как датасет для дообучения открытой модели (`/api/eng/cad-dataset.jsonl`). Подробности и план — `reports/Открытые ИИ-проекты и новые функции.md`.

**Своя модель BSTS (понимание запросов в ИИ-конструкторе)** — обучена методом дистилляции знаний: Claude-учитель написал 840 размеченных запросов на русском, казахском и английском (`data-train/cad-intent.jsonl`, `scripts/cad-intent/gen-data.ts`), на них обучена многоклассовая логистическая регрессия по хешированным символьным n-граммам (8192 признака, 7 классов: пластина, коробка, цилиндр, уголок, шестерня, подставка, другое) — `scripts/cad-intent/train.ts`. Точность на отложенных 20 %: 87,7 %, на запросах, написанных вручную: 90–95 %; при уверенности ≥ 0,8 модель отвечает сама в 64 % случаев с точностью 96,6 %. Размеры извлекаются правилами, деталь строится из проверенного шаблона (`shared/cadIntent.ts`, проверка шаблонов на ядре — `scripts/cad-intent/templates-check.ts`). Ответ за ~20 мс вместо 7–18 с; неуверенные запросы уходят к Claude, кнопка «Не то? Сделать через Claude» есть всегда.

**SAT**: модули Math собираются по спецификации College Board (Algebra 35 %, Advanced Math 35 %, Problem-Solving 15 %, Geometry/Trig 15 %, около четверти вопросов с вписываемым ответом, без повторов одного генератора). Тренировки (`/sat/drills`): самые трудные Math и R&W, только grid-in, слабая тема по статистике ученика, спринт из 20 вопросов — в темпе экзамена (71 с и 95 с на вопрос) с разбором времени.

**Сложнее**: Arduino — ещё 5 уроков (охранная сигнализация, вентилятор с драйвером мотора, умный горшок, радар, робот по линии); CAD — 4 урока (L-кронштейн с ребром жёсткости, шестерня, корпус под плату со стойками, крышка с допуском посадки); дроны — 3 миссии (слалом на время, посадка на движущуюся платформу, сопровождение машины с упреждением; `npx tsx scripts/drone-missions-check.ts` доказывает, что заготовка не проходит, а эталон проходит).

**Алгоритмы** — 64 задачи по 12 темам (дорожная карта: массивы, два указателя, окно, стек, бинарный поиск, интервалы, деревья, графы, перебор, ДП, жадные, математика), задача дня, свой тест, ИИ-разбор принятого решения (асимптотика, сильные стороны, что улучшить, другой подход) и тренировка собеседования с ИИ-интервьюером и таймером. Новые задачи пишутся в `scripts/problems-src.ts` вместе с эталонным решением; `npx tsx scripts/problems-gen.ts` считает ответы тестов и пишет `shared/problemsMore.ts` (решения в приложение не попадают).

**Вайб-кодинг** — 23 урока в 6 направлениях (игры, веб, наука и данные, инженерия, продукты, проверка ИИ), у каждого нового урока план по шагам.

**Telegram-бот** (`server/bot.ts`, `server/teacherBot.ts`)
- Ученик подключает своего ИИ-помощника из раздела «Для родителей»: объясняет темы, разбирает задачи по фото, видит результаты ученика, отвечает только по учёбе и честно говорит, если не уверен. Репетитор, а не решебник.
- Родитель — по своей ссылке: отчёт по пятницам, `/report`, вопросы об успехах ребёнка по данным платформы.
- Учитель — с главной страницы: планы уроков, СОр/СОч и дескрипторы, поиск в интернете и `/research` (глубокое исследование с источниками), сводка по классу и ученику, задания классу, консультации. Сообщение родителям ассистент только готовит: черновик приходит с кнопками «Отправить» и «Отмена», без нажатия ничего не уходит; отправленное видно и на странице родителя.
- Лимиты: ученик и родитель — 60 вопросов в день, учитель — 150 и 15 исследований. Проверка локально: `npx tsx scripts/bot-smoke.ts`, `npx tsx scripts/bot-teacher-smoke.ts [--research]`.

**Завуч**
- **Отчёт по школе** за 7, 30 или 90 дней: ученики, активность, пробники ЕНТ, средний лучший балл и доля проходящих порог по классам, SAT, контрольные, работа учителей, список учеников в зоне риска с причинами (давно не заходил, низкий пробник, контрольные ниже 50%). Выводы ИИ и CSV. Доступ — по таблице `school_admins` или переменной `SCHOOL_ADMIN_EMAILS`; демо-учитель — завуч.

## Контент

Весь учебный контент **синтетический и авторский**: задания в формате Digital SAT, тексты IELTS и задачи по программированию написаны для BSTS. Вопросы 1609SAT, GoPrep, Grader, College Board, IELTS и LeetCode не копировались: это чужие охраняемые материалы. Механики (повтор ошибок, Blitz, адаптивный тест, разметка эссе, игры) повторены своим кодом.

- SAT: 256 вопросов в банке (64 Reading & Writing, 192 Math), 20 уроков по навыкам, бесконечные варианты из 16 генераторов математики, а также «Remix» и генерация новых вопросов от Claude.
- Библиотека: 4 авторских учебника (12 глав, 4 готовых интерактивных опыта) и шпаргалки формул по алгебре, геометрии, физике и химии. Задания College Board, Bluebook и учебники okulyk.kz не копируются: на официальные бесплатные материалы даются ссылки, а полные учебники школа загружает сама — только те, на которые у неё есть права.
- Словарь: 4 юнита по 10 слов. IELTS: 6 тем Part 1, 8 карточек Part 2 с вопросами Part 3, 10 тем Task 2, 4 графика Task 1, 2 текста Reading, 2 записи Listening.
- Кодинг: 20 задач, 12 вопросов Bug Blitz, 5 уроков вайб-кодинга.

Проверка контента (ответы, варианты, эталонные решения задач): `npm run check:content`.

## Ограничения, которые стоит знать

- **Закрытый режим в браузере** засекает выход (вкладка, фокус, полный экран), ставит урок на паузу и показывает выход учителю, но запретить выход страница не может. Настоящая блокировка — нативная обёртка: Assessment Mode на iPad/iPhone, Lock Task Mode на Android через систему управления устройствами школы.
- **Speaking**: распознавание речи делает браузер (Chrome, Edge, Safari). Произношение по тексту оценивается приблизительно; для точной оценки нужен Azure Pronunciation Assessment, как у Grader.
- **Тесты задач** отправляются в браузер, потому что код выполняется там: ученик технически может их увидеть. Для экзаменационных задач нужен серверный исполнитель в песочнице.
- **Баллы** SAT и IELTS — ориентировочные, не официальные.
- **Desmos** встраивается с desmos.com, поэтому нужен интернет; в окне есть кнопка «открыть в новой вкладке».
- **Сканы PDF** без текстового слоя ИИ-панель библиотеки не прочитает (нужно OCR); контрольную по такому PDF Claude составит, потому что получает сам документ.
- **Отчёт завуча** считается запросами по каждому ученику: на сотнях учеников он будет открываться несколько секунд. Cron отчётов родителям за один запуск успевает около 240 секунд работы; на большой школе нужна очередь.
- **Данные учеников** хранятся в `data/bsts.sqlite`. Для реального пилота нужен сервер в Казахстане (закон РК о персональных данных) и согласия родителей. В Claude уходят только тексты ответов и код, без имён.
